# Built-in adversarial red-team of the tool's own proposals

Before ratification the tool should adversarially RED-TEAM its own output across honesty lenses — internal-contradiction, false-precision, scale-unproven, a11y-truth, data-model-truth — and return a ratifiability verdict (blockers / conditions / nits), not just a positive jury score.

This session a jury scored the winner highly, but a red-team then found real honesty failures the jury missed (a self-contradictory headline number; a forecast that implied precision on blocked work; scale asserted but never rendered). The red-team is what made the proposal trustworthy.
