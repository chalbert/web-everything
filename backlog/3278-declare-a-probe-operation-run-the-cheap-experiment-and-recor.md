# Declare a probe operation: run the cheap experiment and record its result on the card

A design argument two panels had circled was settled in two minutes by running one experiment — spawn a detached agent, stop it, resume by session id, observe whether context survived. Nothing declares that shape. mutation-check is the only probe-shaped operation and it is narrow to breaking a guarded line and watching a named test redden. Preparation is repeatedly told to de-risk by probing, and has no operation to run a probe or to attach its result where the next reader will see it.
